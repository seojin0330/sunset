# 노을 공중전 (Sunset Dogfight)

컨트롤러를 기울여서 비행기를 조종하는 4인 공중전 게임이에요.
노트북 4대가 각자 자기 비행기 시점으로 플레이하고, 서버 한 대가 전체 게임을 관리해요.

```
 [컨트롤러1]─USB─[노트북1]─┐
 [컨트롤러2]─USB─[노트북2]─┤
 [컨트롤러3]─USB─[노트북3]─┼── 공유기 ── [서버 J3160]
 [컨트롤러4]─USB─[노트북4]─┘              (+ TV 관전 화면, 선택)
```

---

## 1. 서버 준비 (J3160)

1. **Node.js 설치**: https://nodejs.org 에서 LTS 버전을 설치하세요.
   - 리눅스(우분투)라면: `sudo apt install nodejs npm`. 버전이 18보다 낮으면 nodejs.org 안내를 따라 최신으로 설치하세요.
2. 이 `sunset-dogfight` 폴더를 서버에 통째로 복사하세요.
3. 서버 실행
   - **윈도우**: `start-server.bat` 더블클릭
   - **리눅스**: 폴더에서 `npm install` (처음 한 번, 인터넷 필요) → `npm start`
4. 화면에 이런 주소가 나와요. 이 주소를 기억하세요.
   ```
   노트북에서:  http://192.168.0.10:3000
   ```

> 처음 `npm install` 할 때만 인터넷이 필요해요. 그다음부터는 인터넷이 없어도 돼요.
> 체험전 전에 꼭 미리 설치해 두세요.

**서버 IP 고정 (추천)**: 공유기 설정에서 서버에 고정 IP(예: `192.168.0.10`)를 주면 매번 주소가 바뀌지 않아요.

**윈도우 방화벽**: 처음 실행할 때 "액세스 허용" 창이 뜨면 **개인 네트워크 허용**을 누르세요.
노트북에서 접속이 안 되면 방화벽을 의심하세요.

## 1-2. 예비 서버: 인터넷 호스팅 (Render 무료)

J3160이 고장 나거나 학교 공유기에서 기기끼리 연결이 막힐 때 쓰는 예비 주소예요.
주소가 `https://`라서 **크롬 flags 설정 없이 컨트롤러가 바로 연결돼요.**

**처음 한 번만**
1. [github.com](https://github.com)에 새 저장소를 만들고(Private 가능) 이 폴더를 올려요.
   `node_modules`, `data`는 `.gitignore`에 있어서 자동으로 빠져요.
   ```
   git init
   git add .
   git commit -m "노을 게임"
   git branch -M main
   git remote add origin https://github.com/내아이디/저장소이름.git
   git push -u origin main
   ```
2. [render.com](https://render.com)에 GitHub 계정으로 가입해요.
3. **New → Blueprint** → 방금 만든 저장소 선택 → **Apply**.
   `render.yaml` 설정대로 싱가포르 서버에 무료로 만들어져요 (2~3분).
4. 생긴 주소(예: `https://sunset-dogfight-xxxx.onrender.com`)를 적어 둬요.
   - 비행기 게임: `https://주소/?p=1` ~ `?p=4`
   - TV: `https://주소/?tv`

**코드를 고치면** `git push`만 하면 Render가 자동으로 다시 올려요.

**알아 둘 것**
- 무료 서버는 15분 동안 아무도 안 들어오면 잠들어요. **행사 시작 5분 전에 주소를 한 번 열어** 깨워 두세요 (처음 여는 데 1분쯤 걸려요).
- 서버가 다시 켜지면 오늘의 기록이 지워져요.
- 학교 인터넷이 필요해요. 해외 서버라 비행기 게임은 반응이 아주 살짝 늦을 수 있어요.
- 4명이 **모두 같은 주소**로 들어가야 같이 플레이돼요. J3160 주소와 섞어 쓰면 안 돼요.

## 2. 노트북 준비 (4대 모두, 한 번만)

1. **크롬**(또는 엣지)을 쓰세요. 다른 브라우저는 USB 컨트롤러를 지원하지 않아요.
2. **USB 컨트롤러 허용 설정** (중요!)
   - 주소창에 `chrome://flags/#unsafely-treat-insecure-origin-as-secure` 입력
   - 입력칸에 서버 주소를 적어요. 예: `http://192.168.0.10:3000`
   - 오른쪽을 **Enabled**로 바꾸고 아래 **Relaunch** 클릭
   - 엣지는 `edge://flags`에서 같은 항목을 찾으면 돼요.
   - 이 설정을 안 하면 "컨트롤러 연결이 막혀 있어요" 안내가 떠요.
3. 서버 주소로 접속해요. **노트북마다 다른 번호**를 붙이면 비행기 색이 고정돼요.
   - 노트북1: `http://192.168.0.10:3000/?p=1` (빨강)
   - 노트북2: `http://192.168.0.10:3000/?p=2` (파랑)
   - 노트북3: `http://192.168.0.10:3000/?p=3` (초록)
   - 노트북4: `http://192.168.0.10:3000/?p=4` (노랑)
4. 컨트롤러를 USB로 꽂고 **🎮 컨트롤러 연결** 클릭 → 목록에서 선택
5. 처음 연결하면 **기울기 설정** 창이 떠요. 안내대로 3번 버튼을 누르면 끝이에요.
6. 전체 화면: 윈도우는 **F11**, 맥은 **Cmd + Ctrl + F**

한 번 연결한 컨트롤러는 다음부터 자동으로 연결돼요.

### 맥북(M2)일 때
- **사파리는 안 돼요.** 사파리는 USB 컨트롤러 기능(Web Serial)이 없어서 꼭 **크롬**을 설치해서 쓰세요.
- 학교 관리 맥북이라 크롬 설치나 `chrome://flags` 변경이 막혀 있을 수 있어요. **미리 꼭 확인하세요.**
- 맥북 에어 M2는 USB-C 포트만 있어요. 컨트롤러 연결에는 **USB-C to USB-C 데이터 케이블**이 필요해요.
  - 충전은 MagSafe로 하면 USB-C 포트 2개가 모두 비어요.
- 컨트롤러를 처음 꽂으면 **"액세서리 연결을 허용하겠습니까?"** 창이 뜰 수 있어요. **허용**을 누르세요.
- ESP32-C3 SuperMini는 맥에서 드라이버 설치 없이 바로 인식돼요. Arduino IDE 포트 목록에는 `/dev/cu.usbmodem...` 으로 보여요.
- 체험전 동안은 **충전기를 꽂아 두고**, 저전력 모드는 끄세요.

### TV 관전 화면 (선택)
큰 TV에 `http://서버주소:3000/?tv` 를 띄우면 **화면을 4분할해서 4명의 시점을 동시에** 보여줘요.
가운데에 남은 시간과 전체 레이더, 각 칸 위에 이름·격추 수·체력이 나와요.
구경하는 사람들이 모이게 하는 데 좋아요.

> 4개 시점을 한꺼번에 그려서 노트북 한 대보다 4배 무거워요. TV에 연결하는 컴퓨터는 성능이 좋은 걸 쓰세요.
> J3160 서버로 TV까지 띄우면 버벅일 수 있어요. 그럴 땐 `/?tv&low` 를 쓰거나 다른 노트북으로 띄우세요.

### 노트북이 느리면
주소 끝에 `&low` 를 붙이세요. 예: `http://192.168.0.10:3000/?p=1&low`

## 3. 게임 방법

1. 로비에서 이름을 입력하고 **준비 완료** (컨트롤러 아무 버튼이나 눌러도 돼요)
2. 모든 사람이 준비되면 5초 카운트다운 후 시작
   - **카운트다운 동안 편한 자세로 컨트롤러를 잡고 계세요.** 그 자세가 "수평"이 돼요.
3. 3분 동안 가장 많이 격추한 사람이 우승!
4. 결과 화면 후 로비로 돌아가요. 다음 사람이 이름을 바꾸고 준비하면 돼요.

### 조작

| 입력 | 동작 |
|---|---|
| 좌우로 기울이기 | 선회 |
| 앞으로 숙이기 / 뒤로 젖히기 | 하강 / 상승 (로비에서 **상하 반전** 가능) |
| 🔴 오른쪽 위 | 기관총 (누르고 있으면 연사) |
| 🔵 오른쪽 아래 | 미사일 (노란 네모 = 조준됨, 빨간 네모 = 발사 가능) · 쿨타임 5초 |
| 🟡 왼쪽 위 | 회피 (빙글 돌면서 잠깐 무적 + 미사일 따돌리기) · 쿨타임 4초 |
| 🟢 왼쪽 아래 | 체험 모드: 📯 경적 / 고수 모드: 부스터 |
| 흔들기 | 고수 모드에서 필살기 (게이지가 꽉 찼을 때) |

### 모드
- **체험 모드** (기본): 총알이 잘 맞고, 4번 버튼은 경적이에요. 처음 하는 사람에게 좋아요.
- **고수 모드**: 4번 버튼이 부스터, 컨트롤러를 흔들면 주변 적에게 큰 피해를 주는 필살기.

### 키보드 (컨트롤러 없을 때 / 테스트용)
`←→` 선회 · `↑↓` 상승/하강 · `Space` 기관총 · `K` 미사일 · `L` 회피 · `B` 경적/부스터 · `U` 필살기 · `Enter` 준비

### 맵
- 섬 14개: 뾰족산, 능선, 가운데 **분화구 섬**, 평평한 고원 (고원 위에 **등대**)
- **바위 아치 3개**: 아래로 통과할 수 있어요. 추격을 따돌리기 좋아요
- 바다 위 **돌기둥 무리**: 사이로 빠져나가며 싸울 수 있어요
- 섬과 돌기둥에 부딪히면 **추락** (격추 점수는 아무도 받지 않고 내 추락 횟수만 올라가요)

### 아이템
하늘에 빛기둥이 있는 곳에 아이템이 떠 있어요. 지나가면 먹어요. 레이더에도 점으로 보여요.
- ❤️ 체력 +40
- ⚡ 8초 동안 기관총 연사 2배
- 🛡️ 6초 동안 보호막 (무적)

### 화면 안내
- 오른쪽 아래 **레이더**: 가운데 흰 삼각형이 나, 색깔 삼각형이 적, 빨간 점은 나를 쫓는 미사일
- **노란 마름모**: 적이 움직일 곳을 예측한 조준점. 여기에 맞춰 쏘면 잘 맞아요
- 맞으면 화면 가장자리에 **빨간 표시**가 공격한 방향을 알려줘요
- 연속 격추, 첫 격추, 1위 변동, 마지막 30초를 크게 알려줘요
- 결과 화면에서 최다 피해, 최다 연속 격추, 불사조(가장 적게 격추됨) 상을 줘요

### 기타
- 빈자리는 AI 비행기가 채워요 (로비에서 끌 수 있어요). AI도 미사일을 쏘고, 체력이 낮으면 회복 아이템을 찾아가요.
- 바닥(바다)에 가까워지면 자동으로 기수를 올려줘요. 섬에 부딪히면 추락해요.
- 경기장 밖으로 나가면 자동으로 안쪽으로 돌아와요.
- "오늘의 랭킹"은 서버의 `data/leaderboard.json`에 저장돼요. 지우면 초기화돼요.

## 3-2. 파티 게임 (스모 · 보트 · 달리기 · 미로)

같은 서버, 같은 컨트롤러로 하는 미니게임 4개예요. 비행기 게임 로비의 **🎲 다른 게임 하기** 버튼을 누르면 노트북 4대와 TV가 **다 같이** 파티 게임 화면으로 넘어가요. 돌아올 때는 파티 로비의 **✈️ 노을 공중전** 카드를 누르면 돼요.

- 노트북 주소: `http://서버IP:3000/party.html?p=1` (1~4번)
- TV 주소: `http://서버IP:3000/party.html?tv`
- 로비 위쪽 카드에서 게임을 고르고, 모두 준비하거나 **지금 바로 시작**을 누르면 시작돼요.
- 기울기 설정은 비행기 게임과 같이 써요 (따로 할 필요 없음).

| 게임 | 한 판 | 방법 | 버튼 |
|---|---|---|---|
| 🔴 구슬 스모 | 30초~1분 × 1/3/5판 | 기울여서 공을 굴려 상대를 판 밖으로 밀어내기. 시간이 지나면 판이 줄어들어요 | 빨강 대시 · 파랑 무거워지기 · 흰색 점프 · 검정 브레이크(꾹) · 흔들기 충격파 |
| 🚤 보트 레이스 | 한 바퀴 약 75초 × 1/2/3바퀴 | 섬과 바위 아치 3개를 지나는 물길 경주. 좌우로 조종, 앞으로 숙이면 빨라져요 | 빨강 부스터 · 파랑 물길 복귀 · 흰색 드리프트(꾹) · 검정 경적 · 흔들기 물보라(근처 상대 느려짐) |
| 🏃 허들 달리기 | 약 15초 | 흰색·빨강(위쪽 두 버튼)을 **번갈아** 연타하면 달려요. 허들 앞에서 점프 | 파랑/검정 점프 (뒤로 젖혀도 점프) · 흔들기 스퍼트 1번 |
| 🧩 협동 미로 | 최대 4분 | 4명 기울기의 **평균**으로 판이 기울어요. 구멍을 피해 ⭐까지, 3단계 | 아무 버튼 = 다 같이 점프 (절반 이상이 0.6초 안에 눌러야 함) |

- 스모·보트·달리기는 빈자리를 AI가 채워요. 협동 미로는 사람끼리만 해요.
- 시작 전 6초 동안 화면에 **조작법 카드**가 떠요. 따로 설명 안 해도 돼요.
- 게임별 재미 요소: 스모 ⚡ 번개(먹으면 4초간 크고 무거워짐) · 보트 주황 **부스터 발판**과 손 놓으면 물길로 살짝 돌려주는 **조종 도우미** · 달리기 금색 **오늘의 기록 유령**과 신기록 함성 · 미로 작은 ⭐(하나에 3초 단축)
- **배경음악은 TV 화면에서만** 나와요 (노트북 4대가 같이 틀면 시끄러워서). TV 브라우저는 소리 정책 때문에 화면을 **한 번 클릭**해야 소리가 나요. 노트북에서도 음악을 켜려면 주소 끝에 `&music`.
- 손님이 많을 때는 **허들 달리기 / 구슬 스모(1판)** 가 회전이 빨라요.
- 게임별 "오늘의 기록"은 `data/party-records.json`에 저장돼요 (스모 최다 승, 보트 최고 한 바퀴, 달리기 최고 기록, 미로 팀 기록).
- 키보드: ←→↑↓ 기울이기 · Space(J) 빨강 · K 파랑 · L(Shift) 흰색 · B 검정 · U 흔들기

## 4. 컨트롤러 만들기

### 부품 (1개 기준)
- ESP32-C3 SuperMini
- MPU6050 (GY-521)
- 택트 스위치 12x12x7.3 4개 + 캡 (빨강, 파랑, 흰색, 검정)
- 만능기판 7x9cm, 암 핀헤더, 전선

### 배선

| MPU6050 | ESP32-C3 SuperMini |
|---|---|
| VCC | 3.3V |
| GND | GND |
| SDA | GPIO 6 |
| SCL | GPIO 7 |

| 버튼 (위치 / 캡 색) | 한쪽 다리 | 다른 쪽 다리 |
|---|---|---|
| 오른쪽 위 / 🔴 빨강 (기관총) | GPIO 0 | GND |
| 오른쪽 아래 / 🔵 파랑 (미사일) | GPIO 1 | GND |
| 왼쪽 위 / ⚪ 흰색 (회피) | GPIO 3 | GND |
| 왼쪽 아래 / ⚫ 검정 (경적·부스터) | GPIO 4 | GND |

- 버튼은 저항이 필요 없어요 (보드 안의 풀업 저항을 써요).
- 택트 스위치 다리 4개 중 **대각선 두 다리**를 쓰면 방향을 헷갈리지 않아요.
- MPU6050은 **기판과 평평하게, 변을 나란히** 붙이세요. 방향은 기울기 설정이 자동으로 맞춰줘요.
- GPIO 2, 8, 9는 부팅에 쓰이는 핀이라 비워 뒀어요.

### 펌웨어 올리기
1. **Arduino IDE** 설치 (https://www.arduino.cc/en/software)
2. 파일 → 기본 설정 → "추가 보드 관리자 URL"에 추가:
   `https://espressif.github.io/arduino-esp32/package_esp32_index.json`
3. 도구 → 보드 → 보드 매니저 → **esp32** (Espressif) 설치
4. `firmware/controller/controller.ino` 열기
5. 도구 메뉴 설정
   - 보드: **ESP32C3 Dev Module**
   - **USB CDC On Boot: Enabled** ← 꼭!
   - 포트: 컨트롤러가 연결된 COM 포트
6. 업로드(→) 버튼
   - 업로드가 안 되면: 보드의 **BOOT 버튼을 누른 채로** USB를 꽂고 다시 업로드
7. 도구 → 시리얼 모니터 (115200) 에서 `-1.2,3.4,0,0,0,0,0` 같은 숫자가 계속 나오면 성공
   - 기울이면 앞의 두 숫자가 변하고, 버튼을 누르면 1이 돼요.
   - `ERR,MPU`가 나오면 MPU6050 배선(SDA/SCL/전원)을 확인하세요.

> 시리얼 모니터를 켜둔 채로는 게임에서 컨트롤러가 연결되지 않아요. 확인 후 꼭 닫으세요.

## 문제 해결

| 증상 | 해결 |
|---|---|
| 노트북에서 페이지가 안 열림 | 서버와 같은 공유기에 연결됐는지, 서버 방화벽 허용했는지 확인 |
| "컨트롤러 연결이 막혀 있어요" | 2번의 chrome://flags 설정 (주소의 숫자까지 정확히) |
| 컨트롤러 목록이 비어 있음 | 데이터용 USB 케이블인지, 펌웨어 업로드 시 USB CDC On Boot를 켰는지 확인 |
| 연결은 되는데 반응 없음 | Arduino 시리얼 모니터가 켜져 있으면 끄기 |
| 비행기가 혼자 한쪽으로 돎 | 로비에서 "기울기 다시 설정" |
| 위아래가 반대로 느껴짐 | 로비에서 "상하 반전" 체크 |
| 버벅임 | 주소 끝에 `&low`, 다른 탭/프로그램 닫기 |

## 파일 구성

```
server.js            게임 서버 (라운드, 점수, AI, 랭킹)
party-server.js      파티 게임 서버 (스모·보트·달리기·미로 물리와 AI)
shared/sim.js        비행 물리와 밸런스 숫자 (CFG)
shared/party.js      파티 게임 숫자, 보트 물길, 미로 맵
public/              노트북에서 보이는 게임 화면
  main.js            게임 진행, 화면 표시
  world.js           바다, 하늘, 섬
  planes.js          비행기 모델
  fx.js              총알, 미사일, 폭발
  items.js           하늘에 떠 있는 아이템
  audio.js           효과음
  input.js           컨트롤러/키보드 입력
  party.html         파티 게임 페이지
  party/             파티 게임 화면 (main, sumo, boat, dash, maze)
firmware/controller/ ESP32-C3 펌웨어
```

밸런스(속도, 데미지, 쿨타임, 라운드 시간 등)는 `shared/sim.js` 맨 위의 숫자를 바꾸면 돼요. 파티 게임은 `shared/party.js`의 SUMO / BOAT / DASH / MAZE 숫자를 바꾸면 돼요. 미로 맵은 같은 파일의 글자 그림(`#` 벽, `O` 구멍, `C` 체크포인트, `G` 골)을 고치면 바로 바뀌어요.
